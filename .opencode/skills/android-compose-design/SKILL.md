# android-compose-design

Rubric per screen (1–10): layout/hierarchy, spacing/density, typography, colour/contrast,
iconography, component polish, motion/feedback, empty/loading/error states, dark/light parity,
RTL correctness, tablet adaptation, discoverability, perceived performance.
Rules: spacing scale 4/8/12/16/24/32; type scale with semantic styles; one stroke weight for icons;
24–28dp sheet radii, pill chips; 150–250ms ease-out fades; ≥48dp targets; content descriptions;
Material 3 components must be themed past recognition (no default purple-on-black);
every screen has designed empty/loading/error states; dark-first, light supported via same tokens.
