# Store listing (MS-052, honest claims only)

Short: Local video player + manga reader with optional AI-style enhancement.

Full: Plays local videos and streams (H.264/HEVC/VP9/AV1 via hardware
decoding where the device supports it). Two optional enhancement modes
(Anime, Standard) for sources up to 1440p; everything else plays untouched.
Reads CBZ/ZIP/7z, folders, PDFs, image URLs and pages you open in the
built-in browser. No account, no catalog, no content included. No ads in
the current build.

Claims we do NOT make: perfect playback on every device/TV box (see
unsupported list), content included, cloud features.
